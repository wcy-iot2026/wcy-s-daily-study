# Python `__name__` 详解

> 学习 Python 自定义模块时的核心知识点：搞清楚一个 `.py` 文件的"两种身份"。

## 一、`__name__` 是什么

Python 在**每个 `.py` 文件里自动创建**的一个特殊变量，用来标记"这个文件当前的身份"。不需要自己定义，它天生就在。

## 二、两种取值

| 情况 | `__name__` 的值 |
|---|---|
| **直接运行**这个文件（`python my_module.py`） | `"__main__"`（主程序） |
| 被别的程序 **import 导入** | 模块名，即文件名（如 `"my_module"`） |

## 三、为什么需要区分

假设写了一个模块 `my_module.py`，里面有函数，也有几行测试代码：

```python
def add(a, b):
    return a + b

# ↓ 测试代码
print(add(1, 2))     # 3
```

问题：当别人 `import my_module` 想用 `add` 函数时，这几行**测试代码也会跟着执行**，终端平白冒出个 `3`。

用 `__name__` 就能解决——**只在这个文件被直接运行时才跑测试代码**：

```python
def add(a, b):
    return a + b

if __name__ == "__main__":
    print(add(1, 2))     # 只有直接运行本文件才打印
```

- 直接运行 `python my_module.py` → `__name__ == "__main__"` → 执行测试
- 别人 `import my_module` → `__name__ == "my_module"` → 跳过测试，只提供函数

这就是经典写法 `if __name__ == "__main__":` 的意义：**把"当脚本用"和"当模块用"两种身份的代码分开**。

## 四、双下划线命名约定

`__name__` 这种**前后都有双下划线**的命名，是 Python 的**魔术方法/特殊属性**，由 Python 内置、有特殊含义。常见的还有：

- `__init__`：类的构造函数
- `__main__`：主程序标识
- `__name__`：模块身份标识

> 只有前导双下划线 `__xxx`（后面没有）的是私有变量约定，与魔术方法不同。

## 五、一句话总结

**`__name__` 是文件的"身份证"：自己跑就是 `"__main__"`，被人 import 就是自己的模块名。用它加个 `if` 判断，就能让测试代码只在自己跑的时候执行。**

---

*附：从网页/PDF 复制代码时，有时会带入零宽空格（`&#8203;`，Unicode U+200B）。它不可见但真实存在，会导致变量名对不上、字符串长度异常等诡异问题。遇到"看起来没错却报错"时，用 `repr(s)` 或 `[hex(ord(c)) for c in s]` 检查，或用 `s.replace('\u200b', '')` 清理。*
