# 错题：相对路径 ./ 和直接文件名、绝对路径
【类别】Python 基础
【标签】#path #os #文件操作

## 错误点
分不清 `./xxx`、直接写文件名、绝对路径；写链接的时候混用本地完整路径，上传 GitHub 之后失效。

## 知识点
- `./xxx`：当前目录，标准相对路径
- `xxx`：简写，Python 打开文件等价于 `./xxx`
- `../xxx`：上一级目录
- `D:/xxx`：绝对路径，绑定本机，不适合仓库

## 示例代码
```python
import os
print(os.getcwd())
with open("./test.txt", "w", encoding="utf-8") as f:
    f.write("hello")
