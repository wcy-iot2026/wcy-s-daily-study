# 第19节 类和对象：面向对象基础

> 写项目时，封装设备类、通信类都靠它。本文把核心概念和可运行例子整理在一起，代码均在本机实测通过。

---

## 一、类与对象是什么

- **类（class）**：模板 / 图纸，规定一类东西有哪些属性和行为。
- **对象（object）**：按模板造出来的具体实例。
- 关系：类是图纸，对象是按图纸造出来的产品。

```python
class Device:                 # 定义类
    def __init__(self, name): # 构造方法，创建对象时自动执行
        self.name = name      # 实例属性：每个对象各自一份

    def connect(self):        # 实例方法
        return f'{self.name} 已连接'

dev = Device('传感器A')       # 创建对象
print(dev.connect())          # 传感器A 已连接
```

---

## 二、self、实例属性、类属性

### 2.1 self 是什么

`self` 就是「当前这个对象本身」。调用 `dev.connect()` 时，Python 自动把 `dev` 作为第一个参数传进去，所以你不用手动写。

```python
dev.connect()      # Python 内部等价于 Device.connect(dev)
```

### 2.2 实例属性 vs 类属性

| 类型 | 定义位置 | 归属 | 例子 |
| --- | --- | --- | --- |
| 实例属性 | `__init__` 里 `self.xxx` | 每个对象各自一份 | `self.name` |
| 类属性 | 类体内直接写 | 所有对象共享 | `count = 0` |

```python
class Device:
    count = 0                 # 类属性，共享

    def __init__(self, name):
        self.name = name      # 实例属性，各自独立
        Device.count += 1

a = Device('A')
b = Device('B')
print(Device.count)  # 2
print(a.name, b.name)  # A B
print(a.count, b.count)  # 2 2（通过对象也能读到类属性）
```

⚠️ 坑：在实例方法里写 `self.count += 1` 并不会改类属性，而是给当前对象新建一个同名实例属性，把类属性「遮住」了。要改共享的那份，得用 `Device.count += 1` 或 `cls.count += 1`。

## 三、三种方法

```python
class Device:
    count = 0

    def instance_method(self):        # 实例方法：拿到对象
        return self.name

    @classmethod
    def class_method(cls):            # 类方法：拿到类本身
        return cls.count

    @staticmethod
    def static_method(x):             # 静态方法：不自动传任何东西
        return x + 1
```

- **实例方法**：第一个参数 `self`，拿到某个对象，能读写 `self.name` 这类实例属性。
- **类方法**：`@classmethod`，第一个参数 `cls`，拿到类本身，改的是类属性或用来造实例。
- **静态方法**：`@staticmethod`，没有 `self` / `cls`，就是个写在类里的普通函数。

`cls` 的实战价值在继承时体现：

```python
class Device:
    @classmethod
    def create(cls, name):
        return cls(name)     # cls 是谁就造谁

class Sensor(Device):
    pass

s = Sensor.create('温度探头')
print(type(s))  # <class '__main__.Sensor'>，造出来的是子类
```

## 四、封装：私有属性与 @property

- 约定：属性名前加单下划线 `_xxx` 表示「内部使用，外部别直接改」。
- 用 `@property` 把方法包装成「只读属性」，外部能读、不能随便写。

```python
class Device:
    def __init__(self, name):
        self.name = name
        self._online = False          # 私有约定

    def connect(self):
        self._online = True
        return f'{self.name} 已连接'

    @property
    def online(self):                 # 对外暴露只读状态
        return self._online

dev = Device('传感器A')
print(dev.connect())     # 传感器A 已连接
print(dev.online)        # True
```

实测输出：
```
传感器A 已连接
True
```

## 五、继承与多态

子类继承父类，复用代码并可重写方法。

```python
class Device:
    def __init__(self, name):
        self.name = name
    def connect(self):
        return f'{self.name} 已连接'

class Sensor(Device):                 # 继承
    def connect(self):                # 重写
        return f'{self.name} 正在采集数据'

class Actuator(Device):
    def connect(self):
        return f'{self.name} 已就绪，可执行动作'

for d in [Sensor('S1'), Actuator('A1')]:
    print(d.connect())                # 同一个调用，不同表现 = 多态
```

实测输出：
```
S1 正在采集数据
A1 已就绪，可执行动作
```

## 六、综合例子：设备类 + 通信类

这是项目里最常见的组合：设备负责自身状态，通信类负责发消息。

```python
class Device:
    def __init__(self, name):
        self.name = name
        self._online = False

    def connect(self):
        self._online = True
        return f'{self.name} 已连接'

    @property
    def online(self):
        return self._online


class Communication:
    def __init__(self, protocol):
        self.protocol = protocol

    def send(self, device, msg):
        return f'[{self.protocol}] -> {device.name}: {msg}'


dev = Device('传感器A')
print(dev.connect())
print('online =', dev.online)
comm = Communication('MQTT')
print(comm.send(dev, 'hello'))
```

实测输出：
```
传感器A 已连接
online = True
[MQTT] -> 传感器A: hello
```

要点：
- 设备类只管设备和状态，通信类只管协议和发送 —— **职责单一**。
- 通信类通过 `device.name` 读取设备信息，两个类通过对象协作，而不是写死在一起。

## 七、常见坑

1. **类名后冒号必须是半角 `:`**，写成中文全角 `：` 直接 `SyntaxError`。
2. **别把 `@classmethod` 误注释成「静态方法」**：前者有 `cls`，后者没有。
3. **类型注解不强制检查**：`def f(x: bool)` 里的 `: bool` 只是提示，传 `1` 也能跑。
4. **`self` / `cls` 只是约定名**，不是关键字，但别改成别的名字。
5. **密码等敏感信息不要明文存实例属性**，真实项目要哈希处理。

## 八、总结

| 概念 | 作用 |
| --- | --- |
| 类 / 对象 | 模板 / 实例 |
| `self` | 当前对象，自动传入 |
| 实例属性 | 每个对象独立的数据 |
| 类属性 | 所有对象共享的数据 |
| 实例方法 | 操作某个对象 |
| `@classmethod` / `cls` | 操作类本身、造实例（支持继承） |
| `@staticmethod` | 不依赖对象的工具函数 |
| `@property` | 把方法变只读属性，做封装 |
| 继承 / 多态 | 复用代码、同一调用不同表现 |

面向对象核心思想：**把数据和操作数据的方法封装在一起，对象之间靠接口协作。**
